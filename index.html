Methodology & sources — read this first

Scope. Only six levers: reduce taxes; remove regulations; remove import barriers; liberalise energy markets; data/licensing simplification; capital/talent mobility. Hardware, compute, data, research, capital and federal entries are kept only where the fix is one of those six. Generic “invest more” items were excluded.

Method. Compact evidence was built from fetched page bodies (not search snippets alone): PIB / DPIIT / BIS / RBI / IRDAI / CERT-In / MEITY / CBIC-transcript guides / MERC orders / CEA / NITI / law-firm guides reproducing the notification text. Each row cites the fetched source it relies on. Where the fetched text gives a rate, delay, or count, that number is used verbatim.

What an “impact” means. Quoted saving/delay/penalty figures are from evidence. Inferences the evidence does not state (for example, competitiveness effects or compliance-cost totals) are labelled estimated in that row and are treated as directional, not as measured results.

Known limits (preserved verbatim).

  • PIB (www.pib.gov.in) PressReleasePage fetches loop-redirected in the research runs; PIB text was therefore corroborated via the static PIB PDF host (static.pib.gov.in, 200 OK) and via fetched PIB-query PDFs (Sansad). Treat PIB row citations as corroborated-by-fetched-query, not as a live PIB page fetch.
  • CBIC primary tariff site (www.cbic.gov.in / taxinformation.cbic.gov.in) failed TLS with “invalid peer certificate: UnknownIssuer” (environment proxy); icegate.gov.in duty-details reset. BCD/IGST on HS 8471 is therefore evidenced via fetched CHA/AUCorp/Eximpe guides reproducing the CBIC tariff, plus gst.gov.in homepage (200 OK). Row citations name the guide, not a CBIC primary.
  • Singapore corporate-tax primary (IRAS, iras.gov.sg) returned 404 on the first path; resolved on /quick-links/tax-rates/corporate-income-tax-rates and /taxes/corporate-income-tax/… (200 OK): “flat rate of 17%”. The 17% comparator is primary-verified.
  • Aadhaar Act Sec 29 text (PRS/India Code PDF) was fetched but not carried as a separate action; DAT-05 / DAT-01 subsume the sharing barrier it would have covered. No item was dropped for this reason.
  • Overlap audit (critic prior result): cross-cluster overlaps (especially GPU-duty and CSS appearing under several themes) materially breach a strict distinct-scope assumption. Counts are 10 per cluster by design; overlaps are retained because each entry came from a separate fetched cluster — see Dashboard notes. No item was silently merged.
